DBT
Data Build Tool--a transformation framework that enables analytic to store raw data inside warehouse using SQL

Advance SQL
Source data--> data warehouse--> dbtSQL models --> create analytics data

Focuses on T part in ELT pipeline
source(erp,crs)-> Airbyte-> snowflake->dbt-> staging layer or data test

Core components of DBT
core
1. Model(SQL)
2. Sources(YAML File)
3. Test
4. Snapshot--to track historical changes
5. Seeds 
6. Documentation

GIT repo--> dbt

Integration of snowflake with DBT 
dbt integrates with Snowflake by using the Snowflake adapter and connection profile to run SQL-based transformations, tests, documentation, and lineage directly inside Snowflake.
